02 · Timing

Watch the carry ripple

Gates are not instant. Each one adds a small delay, so after the inputs change the sum flickers through wrong values until the carry has walked from bit 0 to bit 7. This is an event-driven simulation of every gate; drag across the waveform to scrub time.

04 · Scaling

Complexity grows, differently for each adder

The same choices swept from 4 to 64 bits. Ripple carry stays small but its delay grows in a straight line. Carry select grows like √n, lookahead blocks cut the slope, and the prefix adders reach log n delay by spending gates and wires. The dot is your design.

05 · Inside

How the fast adders cheat the carry

A carry into bit i depends on every bit below it. Ripple carry collects that information one bit at a time. Prefix adders combine it in a tree: each dot merges the generate/propagate summary of two spans of bits. Rows are gate levels, so the height of the drawing is the delay. Hover a column to see its carry's cone of inputs.

06 · Verified

Same circuit in Verilog and in the browser

The ALU was first written in Verilog as a fixed 8-bit design. Here it is rewritten with parameters and generate blocks, and the page's gate model mirrors that structure. Both are tested against each other and against a plain arithmetic reference.
