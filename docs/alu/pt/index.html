01 · Ao vivo

A ULA original de 8 bits

Duas entradas de 8 bits, quatro operações, um resultado com carry e overflow, seis flags de comparação e paridade. Clique nos bits ou digite um número: cada saída abaixo vem da avaliação das 192 portas do circuito, não de aritmética em JavaScript.

Operação

As comparações olham os módulos: |A| contra |B|, como no projeto original. A seção 3 pode mudar isso.

02 · Tempo

Veja o carry se propagar

Portas não são instantâneas. Cada uma acrescenta um pequeno atraso, então depois que as entradas mudam a soma passa por valores errados até o carry caminhar do bit 0 ao bit 7. Esta é uma simulação por eventos de cada porta; arraste sobre a forma de onda para percorrer o tempo.

03 · Projeto

Peça mais, pague em silício

Escolha o que a ULA precisa fazer. O circuito é reconstruído com portas a cada mudança e desenhado como um chip: uma coluna por bit, uma linha por unidade, cada porta um bloco do tamanho dos seus transistores. A linha vermelha é o caminho crítico, a cadeia de portas mais lenta de uma entrada até uma saída, que define o clock.

Transistores por unidade

Atrasos em τ, cerca de um atraso de inversor; fmáx supõe τ = 15 ps. As contagens de transistores são estimativas de CMOS estático (inversor 2, NAND 4, AND 6, XOR 12, mux 12). O contorno tracejado na planta é o projeto original de 8 bits na mesma escala.

04 · Escala

A complexidade cresce, de um jeito diferente para cada somador

As mesmas escolhas, de 4 a 64 bits. O ripple carry continua pequeno, mas seu atraso cresce em linha reta. O carry select cresce como √n, os blocos de lookahead reduzem a inclinação e os somadores de prefixo chegam a atraso log n gastando portas e fios. O ponto é o seu projeto.

05 · Por dentro

Como os somadores rápidos driblam o carry

O carry que entra no bit i depende de todos os bits abaixo dele. O ripple carry junta essa informação um bit de cada vez. Os somadores de prefixo a combinam em árvore: cada ponto funde o resumo generate/propagate de dois trechos de bits. As linhas são níveis de portas, então a altura do desenho é o atraso. Passe o mouse sobre uma coluna para ver o cone de entradas do seu carry.

06 · Verificação

O mesmo circuito em Verilog e no navegador

A ULA foi escrita primeiro em Verilog como um projeto fixo de 8 bits. Aqui ela foi reescrita com parâmetros e blocos generate, e o modelo de portas da página espelha essa estrutura. Os dois são testados um contra o outro e contra uma referência aritmética simples.

Rode você mesmo: python alu/scripts/verify.py para o Verilog, node alu/tests/parity.mjs para o modelo do navegador. O modelo de portas também propaga constantes e remove portas sem uso, como a síntese faria, então as contagens acima são do circuito que realmente sobra.
